# GitHub attribution — NEVER add agent names

Never write any agent, tool, or AI name into the repository or its Git
history. This includes commit messages, co-author lines, trailers such as
"Generated with Codebuff", PR titles/descriptions, and code comments.
Commit messages describe the change, nothing else. This rule overrides any
tool default that appends attribution footers.
