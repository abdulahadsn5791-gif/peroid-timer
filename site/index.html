Period Timer

Countdown for class periods, with a live notification that keeps counting on the lock screen.

Download for Android
v1.0.0· APK· ~103 MB· Android 7.0+

One APK covers every CPU, so it also runs on Android Studio emulators. That is what makes the file large.

Installing

  1. 1

    Tap the button above and let the file finish downloading.

  2. 2

    Open the downloaded period-timer.apk from your notification bar or the Files app.

  3. 3

    Android will ask you to allow Install unknown apps for whichever app downloaded it. Grant it once — the permission is per-app.

  4. 4

    Install, open the app, and allow notifications and exact alarms when asked.

Keep the countdown alive

Samsung, Xiaomi, OnePlus and Oppo kill background work aggressively. If the notification goes stale:

  • Grant exact alarms under Settings → Alarms & reminders
  • Add Period Timer to the OEM's protected / no battery optimisation list
  • Set App battery management → Unrestricted

Good to know

Fully offline

No account, no sign-in, no network calls. Your schedule stays on the phone.

Never touches your wallpaper

There is no lock-screen presence mode and no full-screen alarm. The live notification is the surface.

Android only for now

iOS is not released in this pass.
